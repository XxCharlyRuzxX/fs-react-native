# Rate Repository App

This project was developed as an assignment for **Part 10: React Native** of the [Full Stack Open course](https://fullstackopen.com/en/part10).

It is a mobile application built with React Native and Expo that allows users to browse repositories, search and sort them, create accounts, sign in, and write, view, and delete repository reviews.
